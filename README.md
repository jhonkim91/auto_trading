# 한국투자증권 주식 분석 · 자동매매 프로그램

폴더 내 리서치 보고서(`compass_artifact_...md`)의 권고를 그대로 구현한 무료 기반 자동매매 시스템입니다.

- **거래사**: 한국투자증권 KIS Developers REST API (무료, 모의/실전)
- **대상 시장**: 국내주식(KOSPI/KOSDAQ) + 미국주식(NASDAQ/NYSE/AMEX)
- **분석 방식**: 이동평균 골든/데드크로스 · RSI · MACD · 볼린저밴드 · 변동성 돌파(래리 윌리엄스)를 **가중 점수로 종합**
- **리스크 관리**: ATR 기반 포지션 사이징, 손절/익절, 일일 손실 한도, MDD 한도
- **제어/알림**: 텔레그램 봇 (원격 제어 · 매매 알림/리포트 · 수동 주문)
- **기본 모드**: 모의투자(`paper`) — 충분히 검증 후 실전 전환

> ⚠️ 자동매매는 원금 손실 위험이 있습니다. 본 프로그램은 투자 권유가 아니며, 반드시 모의투자 → 소액 실전 순서로 검증하세요.

## 1. 사전 준비

### (1) 한국투자증권 KIS Developers 신청
1. 한국투자증권 계좌 개설
2. [KIS Developers 포털](https://apiportal.koreainvestment.com) 에서 서비스 신청
3. **APP Key / APP Secret** 발급 (모의투자 계좌는 별도 신청)
4. 모의투자: [모의투자 신청](https://securities.koreainvestment.com) 후 모의 계좌번호 확인

### (2) 텔레그램 봇 생성
1. 텔레그램에서 **@BotFather** 검색 → `/newbot` → 봇 토큰 발급
2. 본인 **chat_id** 확인: **@userinfobot** 에게 말 걸기, 또는 봇과 대화 후
   `https://api.telegram.org/bot<토큰>/getUpdates` 접속

### (3) 파이썬 환경 (Python 3.11 권장)
```bash
pip install -r requirements.txt
```

## 2. 설정

`.env.example` 를 복사해 `.env` 로 만들고 값을 채웁니다.

```bash
cp .env.example .env   # Windows: copy .env.example .env
```

| 항목 | 설명 |
|------|------|
| `TRADING_MODE` | `paper`(모의) 또는 `real`(실전). **처음엔 paper** |
| `KIS_PAPER_APP_KEY/SECRET` | 모의투자 앱키/시크릿 |
| `KIS_PAPER_ACCOUNT` | 모의 계좌 `12345678-01` 형식 |
| `KIS_REAL_*` | 실전 전환 시에만 |

GUI 상단에는 엔진 버튼 옆에 계좌 모드 전환 버튼이 있습니다. `paper` 화면은 모의투자 배너와 `KIS_PAPER_ACCOUNT`, `real` 화면은 실전투자 경고 배너와 `KIS_REAL_ACCOUNT`를 적용합니다. GUI 설정 탭에서도 `KIS_PAPER_ACCOUNT`와 `KIS_REAL_ACCOUNT`를 별도 입력란으로 저장합니다.
| `TELEGRAM_BOT_TOKEN` | BotFather 봇 토큰 |
| `TELEGRAM_ALLOWED_CHAT_IDS` | 본인 chat_id (쉼표로 여러 개) — **이 ID만 봇 제어 가능** |

전략·리스크 파라미터는 `config.yaml` 에서 조정합니다 (감시 종목, 지표 가중치, 손절/익절, 손실 한도 등).

## 3. 실행 — 윈도우 GUI 앱 (권장)

가장 쉬운 방법은 **`run_app.bat` 더블클릭** 입니다 (또는 `python app.py`).

- 처음 실행 시 필요한 패키지를 자동 설치합니다.
- 창 상단에서 **엔진 시작 / 자동매매 ON·OFF / 즉시 스캔 / 텔레그램 봇 시작**을 버튼으로 제어합니다.
- **📊 대시보드** 탭: 국내 원화·미국 달러 예수금/총평가/평가손익 **분리 카드**, 국내·미국 보유종목 표(손익 색상 구분), 통화별 포트폴리오 비중 막대
- **📒 매매일지** 탭: 주문 기록(시각·종목·구분·수량·가격·금액·실현손익·사유·결과)을 자동 저장(SQLite `trades.db`)하며, `paper`/`real` 모드별로 화면·리포트·실패기록 정리를 분리 표시
- **📈 리포트** 탭: **일일/주간** 실적(거래수·실현손익·승률·매매금액) 카드 + 최근 14일 일별 손익 막대그래프
- **📡 시그널** 탭: 종목별 매수/매도 점수와 판정
- **🛒 수동 주문** 탭: 종목·수량·시장 선택 후 매수/매도, 국내 전체청산
- **⚙ 설정** 탭: 거래모드(paper/real)·텔레그램 chat_id·봇 토큰 입력·저장(.env 갱신), **🔎 내 chat_id 자동 찾기**
- **📜 로그** 탭: 실시간 동작 로그

> 디자인은 다크 카드형 UI로 개선했습니다(순흑/순백 회피, 손익 녹색/적색 구분 — fintech 대시보드 디자인 가이드 반영). 매매 발생 시 매매일지·리포트가 자동 갱신됩니다.

### 단일 실행파일(.exe)로 만들기 (선택)
`build_exe.bat` 더블클릭 → `dist\자동매매.exe` 생성. exe 옆에 `.env` 와 `config.yaml` 을 두고 실행하세요.

## 3-1. 실행 — 명령줄(CLI)

```bash
# 1) 설정·연결 점검 (토큰 발급 + 잔고조회 테스트)
python run.py check

# 2) 백테스트 (실행 전 전략 검증 — 수수료/슬리피지 반영)
python run.py backtest 005930      # 국내 종목코드
python run.py backtest AAPL        # 미국 심볼

# 3) 자동매매 + 텔레그램 봇 가동
python run.py                      # 자동매매 루프 자동 시작
python run.py --no-auto            # 봇만 켜고, /auto on 으로 수동 시작
```

권장 순서(리서치 보고서 9항): ① `check` 로 연결 확인 → ② `backtest` 로 전략 검증(샤프·MDD·승률) → ③ `paper` 모드 실시간 페이퍼 트레이딩 1~2개월 → ④ 소액 `real` 전환.

## 4. 텔레그램 명령어

| 명령 | 기능 |
|------|------|
| `/help` | 도움말 |
| `/status` | 엔진 상태 (모드·자동매매 ON/OFF·한도) |
| `/portfolio` | 보유 종목·평가손익 리포트 |
| `/auto on` / `/auto off` | 자동매매 ↔ 신호 알림만(반자동) 전환 |
| `/run` | 즉시 1회 스캔 실행 |
| `/signals` | 최근 종목별 시그널 요약 |
| `/buy 005930 10` | 수동 매수 (국내) |
| `/buy AAPL 1 us NAS` | 수동 매수 (미국) |
| `/sell 005930 10` | 수동 매도 |
| `/liquidate` | 국내 보유 **전체 청산** |

매수/매도 체결, 손절/익절, 한도 도달 시 알림이 자동 전송됩니다.

run.py                  CLI 진입점 (check / backtest / run)
.env                    민감정보 (앱키·토큰) — git 제외
src/
  config.py             설정 로더 (paper/real 분기, 도메인 결정)
  kis_api.py            KIS REST 클라이언트 (토큰캐싱·유량제어·국내/해외 시세·주문·잔고)
  indicators.py         기술적 지표 (MA·RSI·MACD·볼린저·ATR·변동성돌파)
  strategy.py           종합 시그널 엔진 (가중 점수 합산)
  risk.py               리스크 관리 (포지션 사이징·손절/익절·일손실·MDD)
  trader.py             매매 엔진 (데이터→시그널→리스크→주문 파이프라인)
  telegram_bot.py       텔레그램 제어/알림/수동주문 (chat_id 화이트리스트)
  backtest.py           이벤트 드리븐 백테스터
  logger.py             회전 로그 (logs/autotrader.log)

### 동작 흐름
데이터 수집(KIS REST 일봉/현재가) → 종합 시그널(5개 지표 점수 합산, 임계치 초과 시 매수/매도) → 리스크 검증(포지션 사이징·한도) → 주문 실행(유량제어) → 로깅 → 텔레그램 알림.

## 6. 주요 설계 근거 (리서치 보고서 반영)

- **토큰 관리**: 24시간 유효 토큰을 `token.dat` 에 저장·재사용, 6시간 주기 갱신 (잦은 발급 1분 제한·이용제한 방지)
- **유량 제어**: 슬라이딩 윈도우로 모의 초당 4건 / 실전 초당 18건 (한도보다 보수적)
- **종합 시그널**: 단일 지표를 '매매 버튼'이 아닌 '상태 표시등'으로 다중 확인
- **변동성 돌파**: `목표가 = 시가 + (전일고가-전일저가)×K`, K=0.5 — 코스닥 등 변동성 큰 시장에 유효
- **리스크 우선**: 거래당 위험 1~2%, 진입과 동시에 손절, 일손실·MDD 한도 도달 시 매매 중단/청산
- **모드 분리**: 주문 TR_ID 가 모의(`VTTC...`)/실전(`TTTC...`)로 자동 분기

- 백테스트는 과최적화·미래참조 위험이 있으며 과거 성과가 미래를 보장하지 않습니다.
- 시스템 장애·네트워크 단절·오주문에 항상 대비하고, 손실 한도를 반드시 설정하세요.
- 해외주식은 지정가 주문이 기본이며, USD 잔고/환전이 필요합니다.
